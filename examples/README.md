# SMS-OCP examples

This directory contains one solver entrypoint for each optimal-control
problem. Solver scripts build the OCP, run the algorithm, save the numerical
solution, and create static diagnostic plots.

## Problems

| Problem | Solver |
|---|---|
| Space Shuttle Reentry Trajectory | `solve_space_shuttle_reentry.py` |
| Constrained Double Integrator | `solve_constrained_double_integrator.py` |
| Constrained cart-pole swing-up | `solve_cart_pole_swing_up.py` |
| Jacobson–Lele State-Constraint Example | `solve_jacobson_lele_state_constraint.py` |
| High-frequency narrow corridor | `solve_narrow_corridor.py` |
| Penicillin Fed-Batch Fermentation | `solve_penicillin_fed_batch_fermentation.py` |
| Rayleigh mixed-constraint problem | `solve_rayleigh_mixed.py` |
| Robot path planning | `solve_robot_path_planning.py` |
| State-Constrained Van der Pol Oscillator | `solve_state_constrained_van_der_pol_oscillator.py` |

## Sources

See [Example sources](SOURCES.md) for the single authoritative source assigned
to each problem.

## Reference results

`outputs/` contains checked-in reference solutions, summaries, static figures,
and selected GIFs generated by the example scripts.

## Typical use

From the project root:

```powershell
python examples/solve_constrained_double_integrator.py
```

Each solver writes its numerical result and static diagnostic figures to
`outputs/`.
